## 📖 Overview

**Nike Store** is an e-commerce storefront project showcasing front-end development skills. It features a product catalog, shopping cart UI, and responsive design inspired by the Nike brand.

> 🎯 **Purpose:** Front-end practice project demonstrating HTML, CSS, and JavaScript skills

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 👟 **Product Catalog** | Display products with images and details |
| 🛒 **Shopping Cart** | Add/remove items from cart |
| 📱 **Responsive Design** | Mobile-friendly layout |
| 🎨 **Modern UI** | Clean, brand-inspired design |
| ⚡ **Fast Loading** | Optimized front-end assets |
